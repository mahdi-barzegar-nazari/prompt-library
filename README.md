# 📝 CS & Learning Prompt Library

A curated collection of modular, production-ready system prompts designed to transform AI models (ChatGPT, Claude, Gemini) into structured mentors, interactive tutors, and academic execution engines.

</div>

---

## 📖 Overview

This repository contains vendor-neutral, portable prompt files (`.txt`) tailored for Computer Science students and academic workflows.

Instead of generating passive answers or doing homework for you, these prompts configure models to enforce active recall, Socratic scaffolding, and structured problem-solving.

---

## 🚀 How to Use

1. Choose a prompt from the **Available Prompts** table below.
2. Copy the full raw text from the `.txt` file.
3. Paste it as a **System Prompt** (e.g., in Custom Instructions, Projects, or as the initial setup message in a new chat).
4. Start your interactive session!
